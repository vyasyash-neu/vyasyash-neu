### Things I've built recently

**[Home-Finder](https://home-finder-gules.vercel.app/)** pulls 15K+ Boston rental listings from 80+ brokers into one place, collapses duplicate listings with 99% accuracy, and answers tenant-law questions with pgvector RAG.

**[CartVista](https://github.com/MicroServices-Project-Org/Python-Microservices)** is a 7-service e-commerce platform in Spring Boot and FastAPI. I built it to get reliability right: a Kafka transactional outbox so no order event gets lost, circuit breakers, full metrics, logs, and traces, and 235 tests.

**[Conflict Monitor](https://github.com/vyasyash-neu/conflict-monitor)** ingests 13K+ geolocated events with concurrent Go, classifies them with Llama, and exposes a 7-tool MCP server so you can just ask an LLM what's happening where.

There's more on my [portfolio](https://yashvyas-portfolio.netlify.app), including older projects like Eventify, Roomie, and Rapid Aid.
